Which views do you want for Receipts?

Pick one or more — these are the ways to browse past orders

A

Dense Table

Spreadsheet-style rows: Order#, Date, Customer, Driver, Address, Postcode, Amount, Status. Compact, scannable, sortable columns. Best for bulk lookup and filtering.

# Date Customer Driver Postcode Amount Status
#A1B2C3 08 Jun 16:42 James K. Ali RH2 7AB £24.50 Delivered
#D4E5F6 08 Jun 16:18 Sarah M. Raj RH1 4CD £18.90 Delivered
#G7H8I9 08 Jun 15:55 Tom B. Ali RH2 9EF £31.00 Failed
B

Receipt Cards

Each order as a card showing full details at a glance: customer, driver, items summary, address, amount. Richer but fewer per screen. Good for reading individual orders.

C

Both — Toggle Between Views

Table view as default (fast scanning), card view on demand (full order detail). Toggle button top-right. Click a table row to see receipt card detail in a slide-out drawer.

D

Timeline / Day Groups

Orders grouped by date with a day header (Today, Yesterday, 07 Jun…). Within each day, rows sorted by time. Good for end-of-day review. Can combine with table or cards.
